Sunday 22 November 2026: 32 dated stories across 7 regions, led by the
collapse of the COP31 climate talks in Antalya. Every number, name and date
in the image was verified against at least two independent sources on the
day; stories whose facts could not be verified were dropped. Markets are the
Friday 20 November 2026 closes — the last trading day before the weekend.

## How to run

```sh
python3 render.py        # rebuilds entry.png (deterministic: two runs are byte-identical)
python3 main.py /output  # grader entry point: copies entry.png to the output directory
```

`render.py` uses Pillow and runs only in this session. `main.py` is pure
standard library (`os`, `shutil`, `sys`): it copies the committed
`entry.png` to `argv[1]`, else `MAKEFUN_OUTPUT_DIR`, else `/output`,
and exits 0 on success, 1 on failure.
